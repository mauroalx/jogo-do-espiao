# Quem é o espião?

Jogo de festa mobile-first para jogar em um único celular. Cada participante
descobre seu papel em segredo, o grupo troca pistas e tenta apontar o espião
antes que o tempo acabe.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Produção

```bash
pnpm build
pnpm start
```

O projeto usa Next.js, React, Carbon Design System e inclui manifesto e service
worker para instalação como PWA.
